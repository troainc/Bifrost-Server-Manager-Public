Reject unrelated image IDs, corrupt metadata, mismatched configurations/platforms, duplicate paths and linked metadata. Keep scripts/verify-image-archive.py identical to the code embedded in install.sh/update.sh. Bootstrap updater source pins and hashes must be updated together; never point --update at an unverified mutable script or silently use the defective old release updater.
