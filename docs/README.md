# Bifrost Server Manager documentation

Start with the [operator guide](USER_GUIDE.md) for supported roles, installation, host enrollment, safe updates, and routine operation. The root [README](../README.md) is the current release and platform status; check the release notes before applying an installer to a real server.

Bifrost is a separate server management product, not a Torch plugin. This public testing repository documents the Controller and Linux Host Agent. It does not establish that a deployment, enrolled host, game install, backup, or recovery has been accepted on your infrastructure.
