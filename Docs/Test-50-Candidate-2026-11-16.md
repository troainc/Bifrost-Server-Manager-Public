# Test50 Steam and file-management candidate

This is a candidate for controlled owner testing. Test49 remains delivered until a signed immutable Test50 release is published and verified. Existing features, settings, accounts, MFA, keys, enrollment, games, worlds and old releases are retained.

The shared manager now uses one **Install server** flow for an executable game blueprint: it suggests a compatible Host, a useful name, two CPU cores within the Host/recipe limits, and non-conflicting ports. Advanced resource and package tools remain available. Game terms and vendor ownership are still explicit. A descriptive catalogue entry is not a working runtime recipe.

The reviewed catalogue contains22 signed targets: the original six Minecraft/Torch recipes plus IOSoccer, No More Room in Hell, Pirates Vikings and Knights II, Team Fortress2, Action Half-Life2, BrainBread2, Codename CURE, Counter-Strike Source, Day of Defeat Source, Empires, Fistful of Frags, Garry's Mod, Half-Life Deathmatch Source, Black Mesa, Left4Dead2 and Zombie Panic Source. Each new title passed a real anonymous vendor download, readiness, typed settings, stop and restart check under rootless Podman. Three native runtimes have independently verified cold OCI imports. Public HTTPS installation is not yet accepted. Required Agent update and target-platform acceptance remain separate from panel updates.

Game blueprints supports grid/list and account-scoped favourites. Live visuals preserve actual player totals, per-server status and Host/process readings, with unknown/partial/stale distinctions. Console history is loaded when opened; Follow never starts a game. Files retains hierarchy, keyboard actions, drag/drop, upload/download, rename, move, Trash/restore and previews, and adds icon view, bounded file/directory copy and ZIP browsing/extraction. Extraction uses a new destination with no overwrite; protected runtime mounts remain enforced by the Host. Advanced file actions need the matching capable Linux Agent. Shared action results use scoped toasts.

The frozen TROA identity, detailed original artwork, black shell and readable glass remain. Catalogue search/filter/view controls share one desktop toolbar; one heading and individual readable game surfaces replace duplicate headings and an enclosing glass card. Responsive checks cover1440,768 and390 pixels. Automated accessibility is finite and does not replace manual assistive-technology or touch acceptance.

Verification before final distribution integration:2395 Linux checks pass, zero failures,11 explicit environment gates;123 focused checks/eight launcher checks; seven actual database and four actual generic rootless cases separately pass. Each separately compiled edition passes114 browser checks and89 automated accessibility states. Publisher provenance verification passes19 cases. New runtime scans find zero HIGH/CRITICAL issues and zero detected secrets, with30 MEDIUM/five LOW advisories that have no fixed package version in those scan records. This does not mean vulnerability-free. Exact final distribution images, recovery, public installer suites and anonymous HTTPS acceptance still require their own receipts.

Known scope:471 catalogue definitions do not mean471 executable recipes. Jabroni Brawl's native server crashes on startup and Nuclear Dawn requires owned Steam content; neither is represented as ready. Secure Steam account/Guard and required-token flows, wider typed settings/live APIs, game software update transactions and full cross-Host clone/move are unfinished. Gate remains opt-in experimental. Fenrir is unavailable. No universal compatibility or unrestricted production-readiness claim is made. No paid services, billing changes or Actions dispatch are used. Disposable Ubuntu games, containers, databases, archives and builders are removed under exact ownership checks as stages complete.
