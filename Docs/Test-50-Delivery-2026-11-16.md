# Test50 public distribution

Published November 16, 2026 as an immutable controlled-testing prerelease: [release and assets](https://github.com/troainc/Bifrost-Server-Manager-Public/releases/tag/v0.1.0-installtest.50). All28 assets passed anonymous HTTPS size/SHA256 verification and both offline bootstrap signature verifiers. Older releases remain intact.

The matching Debian/Ubuntu install and update commands are available through the existing [TROA Bifrost testing page](https://therealmsofasgard.com/gaming-hub/bifrost-server-manager). They verify the exact installer hash before execution. Install and panel-only update remain separate commands; the site has no wipe/reinstall controls. Updating the panel does not update an enrolled Host Agent, its locally approved policy or game software automatically.

Installer SHA256: `b821ba77f117db5a909159dc68a7638ac98d9feda45adadf1d92762ca0116f77`.

The signed catalogue contains22 targets: the original six Minecraft/Torch recipes and16 additional Steam titles. New targets are IOSoccer, No More Room in Hell, Pirates Vikings and Knights II, Team Fortress2, Action Half-Life2, BrainBread2, Codename CURE, Counter-Strike Source, Day of Defeat Source, Empires, Fistful of Frags, Garry's Mod, Half-Life Deathmatch Source, Black Mesa, Left4Dead2 and Zombie Panic Source. Each new title has real vendor download/install/settings/provider stop/start/readiness evidence. Three pinned native runtimes are fetched as verified public OCI archives under rootless Podman. No vendor game content is redistributed.

For a fresh Host, use the matching Agent and explicitly approve its bundled recipes during setup. Existing Hosts retain their original policy and profiles when Agent code is upgraded; new recipe approval is a separate local operation. An older/mismatched Host will not advertise the new recipe digests as compatible. No account, MFA, key, enrollment, world, volume or timer is silently replaced or enabled.

Signed recipes have a shorter **Install server** flow with compatible Host/name/resource/port suggestions and exact placement confirmation. Catalogue grid/list and account-scoped favourites remain alongside advanced tools. Files retains the existing explorer actions and adds bounded copy plus ZIP hierarchy browsing/safe extraction. Read-only runtime paths and protected mount roots remain enforced by the Host. Console loads retained history on entry; Follow does not start a game. Live player totals preserve unknown/stale/partial distinctions. Scoped action toasts and the original frozen TROA glass design remain.

Verification includes2395 passing Linux cases, seven actual database and four actual generic rootless cases,20 final publisher/version checks,149 public Python checks (three root-only cases separately pass),67 Node checks, exact customer isolation/scans, the actual22-target Linux Agent, migrations and two encrypted restores. Both actual shipped web editions separately pass114 browser checks and89 automated accessibility states. A cold install using the published Agent, real publisher signature and default HTTPS downloader installs Counter-Strike Source, saves settings, stops without SIGKILL and returns online after restart. Its owned2.6GiB fixture is removed.

The three customer application images have zero detected vulnerability/secret findings in their retained scans. The native game runtimes have zero HIGH/CRITICAL findings or detected secrets, with 30 MEDIUM/five LOW advisories without fixed versions in those scan records. This is not a vulnerability-free certification.

This release does not complete universal471-game installation or every AMP3 capability. Jabroni Brawl still crashes during native startup; Nuclear Dawn requires owned Steam content. Wider authentication/recipes/settings/live API coverage, game-software update transactions and full clone/move remain unfinished. Gate stays opt-in experimental. Fenrir was unavailable and was not remotely updated. Actual target OS/game/player, manual accessibility/touch, off-host recovery and sustained-operation acceptance remain required before a general production claim.

No paid services, billing changes or Actions dispatch are used. Disposable Ubuntu game/database/browser fixtures, four retained build/release workspaces and candidate runtime/application images are removed. No global prune, WSL shutdown or VHD compaction occurred. Raw production preservation records remain on the server; only a fixed safe pass/fail summary is retained locally. This documentation update does not modify the immutable Test50 assets or deployed runtime.
