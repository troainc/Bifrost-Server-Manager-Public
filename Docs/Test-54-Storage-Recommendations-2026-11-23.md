# Test 54 — Recommended installation storage

Test54 replaces the timed storage-test waiver with ordinary disk-space recommendations. Low or unreported game/image free space does not block a new installation. Setup and review show the recommended space and available capacity so the administrator can decide whether to continue. Existing signed recipe disk values remain unchanged and include planning headroom in the recommendation.

There is no waiver setting, expiry, special instance ID or additional storage consent. Legacy Agent environment values are ignored. The Controller accepts bounded old heartbeat metadata during upgrades, discards it and never uses it to change authority or instance identity. Existing Agents must receive the matched compiled update to use advisory checks locally; panel updates alone do not update enrolled Agents.

CPU/RAM/port policy, Host freshness, permissions, MFA/license/terms, fleet isolation, approved publisher signatures, download/file limits, private asset hashes, rootless confinement and recovery remain enforced. An actual full filesystem still fails an operation with retained diagnostic/recovery evidence. Recommendations do not guarantee an installation fits. SE2 still needs the operator's exact private server ZIP and OCI runtime on the selected Host; neither is distributed by Bifrost. Existing worlds and accounts are preserved; this release does not wipe a server or recover lost login credentials.

Verification includes 2,413 Linux passes with zero failures and 11 explicit environment gates, plus 38 real PostgreSQL/HTTP checkpoints. The API tests verify low/unknown space, SE2 creation without an exception, inert legacy metadata, configuration retention and unchanged authorization/resource/port/recovery gates. Eight compiled SE2 storage setup scenarios across desktop/mobile and five onboarding/pairing scenarios pass without page errors or external requests. Public installer checks cover 161 Python cases (three root cases run separately) and 67 Node cases. Exact artifact/source identities and signatures are supplied with the matched release. These results do not claim actual SE2 game startup on another machine.

Use the matched Debian/Ubuntu commands from the main Bifrost page once publication is verified. Prior releases remain immutable. Live player connection, Discord, soak, game backup/restore and Windows-native acceptance are separate checks.
