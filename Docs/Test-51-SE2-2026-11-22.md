# Test 51: SE2 Online blueprint

Test 51 adds the signed Space Engineers 2 / SE2 Online 0.18.4 blueprint,
server/world/water configuration and the Linux Host approval helper to the
compiled customer distribution. The Controller includes the additional signed
public catalogue and trust ring with non-root-readable directories. The
original 22 download recipes and their signatures remain unchanged.

SE2 requires rootless Podman and Wine. Before installing an SE2 game server,
the operator must stage the exact standalone ZIP and automatic OCI archive in
a private directory owned by the unprivileged Host service account. These
private files are not part of this public release. Follow `se2online/README.md`
in the matched Linux Host archive, then run its
`dist/configure-se2-provisioning.js` with the existing Host config, private
asset directory and the two files in `se2online/distribution/`. Stop the Agent
before approval; restart it afterward. Keep existing enrollment and game data.

The UI selects a prepared Host, binds the chosen configuration into the signed
job, reserves adjacent game/query UDP ports and waits for a fresh hosted-world
status. An unprepared Host does not advertise SE2 installation. Optional
Discord configuration remains a separate export and sends no messages by
itself. No vendor game files, private OCI runtime, credentials or signing
private keys are distributed.

This is a controlled-testing prerelease. Recorded private-source acceptance
includes an actual automatic SE2 install and normal provider stop/start;
live player joining, live Discord, soak, backup/restore and Windows-native
SE2 acceptance remain separate. A new public Controller installation is not
proof of SE2 game acceptance on a particular Host. Prior release assets remain
immutable. The separate Debian wipe helper requires an interactive exact
confirmation and is never run by the installer.
